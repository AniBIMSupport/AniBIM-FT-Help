Installation & activation

From request to ready in eight clear steps.Von der Anfrage bis zur Nutzung in acht klaren Schritten.

Use this process when AniBIM FT opens the activation window in Revit.

1

Request trial or licence

Use the trial page or contact AniBIM Support.

2

Receive installer link

Download the approved setup package.

3

Install AniBIM FT

Run the installer for your Revit version.

4

Start Revit

The activation window opens when no valid licence is found.

5

Copy Machine ID

Copy the ID shown in the activation window.

6

Receive licence file

AniBIM Support sends the signed machine-bound licence.

7

Select licence file

Choose the received AniBIM_FT.lic file.

8

Start working

AniBIM FT is ready in the same Revit session.
