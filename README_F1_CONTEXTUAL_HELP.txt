AniBIM FT F1 Contextual Help Update

1. Replace the project RibbonBuilder.cs with developer-code/RibbonBuilder.cs.
2. Upload the website files to GitHub Pages.
3. Hover an AniBIM ribbon command in Revit and press F1.
4. Revit opens docs.html in the current Revit language and jumps to the matching tool.

URL format:
https://anibimsupport.github.io/AniBIM-FT-Help/docs.html?lang=en&from=revit&tool=MeshCutPlan#meshcutplan

The website highlights the tool card and shows an "Opened from Revit" notification.
