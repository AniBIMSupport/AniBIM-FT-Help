AssemblyBaugruppen

Assembly CreatorBaugruppenersteller

What it doesFunktion

Creates a Revit assembly from the selected production elements and guides you through choosing the main member, assembly name and creation options.Erstellt aus den ausgewählten Produktionselementen eine Revit-Baugruppe und führt durch Hauptbauteil, Baugruppenname und Erstellungsoptionen.

Typical workflowTypischer Ablauf

  1. Select the elements that must belong to the new assembly.Wählen Sie die Elemente aus, die zur neuen Baugruppe gehören sollen.
  2. Start Assembly Creator from the Assembly panel.Starten Sie den Baugruppenersteller im Bereich Baugruppen.
  3. Choose the main member and review the proposed assembly name and options.Wählen Sie das Hauptbauteil und prüfen Sie den vorgeschlagenen Baugruppennamen sowie die Optionen.
  4. Create the assembly, then verify its members and name in Revit.Erstellen Sie die Baugruppe und kontrollieren Sie anschließend Mitglieder und Namen in Revit.
AssemblyBaugruppen

Assembly EditorBaugruppen-Editor

What it doesFunktion

Reviews an existing Revit assembly and lets you add, remove or reorganise members without rebuilding the assembly from the beginning.Prüft eine vorhandene Revit-Baugruppe und ermöglicht das Hinzufügen, Entfernen oder Neuordnen von Mitgliedern, ohne die Baugruppe neu zu erstellen.

Typical workflowTypischer Ablauf

  1. Select one element that belongs to the assembly you want to edit.Wählen Sie ein Element der Baugruppe aus, die bearbeitet werden soll.
  2. Open Assembly Editor.Öffnen Sie den Baugruppen-Editor.
  3. Review the current members and change the included elements as required.Prüfen Sie die aktuellen Mitglieder und ändern Sie die enthaltenen Elemente nach Bedarf.
  4. Apply the changes and confirm that the assembly remains valid.Übernehmen Sie die Änderungen und kontrollieren Sie, dass die Baugruppe gültig bleibt.

Rule SelectionRegelwahlen

What it doesFunktion

Builds a selection from multiple parameter and category rules, so large model sets can be found consistently instead of selected manually.Erstellt eine Auswahl aus mehreren Parameter- und Kategorieregeln, damit große Modellmengen reproduzierbar statt manuell gefunden werden.

Typical workflowTypischer Ablauf

  1. Open Rule Selection with or without a starting selection.Öffnen Sie die Regelauswahl mit oder ohne vorhandene Auswahl.
  2. Add the required category and parameter conditions.Fügen Sie die benötigten Kategorie- und Parameterbedingungen hinzu.
  3. Choose how the rules are combined and preview the matching elements.Legen Sie fest, wie die Regeln kombiniert werden, und prüfen Sie die Treffer.
  4. Apply the result to replace or extend the active Revit selection.Übernehmen Sie das Ergebnis als neue oder erweiterte Revit-Auswahl.

InvertUmkehren

What it doesFunktion

Inverts the current selection within the active view, selecting visible eligible elements that were not selected and removing the previously selected ones.Kehrt die aktuelle Auswahl in der aktiven Ansicht um: sichtbare geeignete, bisher nicht ausgewählte Elemente werden ausgewählt und die bisherige Auswahl wird entfernt.

Typical workflowTypischer Ablauf

  1. Create an initial selection in the active view.Erstellen Sie eine Ausgangsauswahl in der aktiven Ansicht.
  2. Run Invert from the Select panel.Starten Sie Umkehren im Bereich Auswählen.
  3. Review the newly selected complementary set.Prüfen Sie die neu ausgewählte Gegenmenge.
  4. Continue with the next modelling, visibility or review command.Fahren Sie mit dem nächsten Modellierungs-, Sichtbarkeits- oder Prüfwerkzeug fort.

  2. Run Toggle Start Join.Starten Sie Startverbindung umschalten.
  3. Revit switches the join state at the start end of every supported beam.Revit wechselt den Verbindungsstatus am Startende jedes unterstützten Trägers.
  4. Inspect the geometry and repeat if the previous join state is required.Prüfen Sie die Geometrie und wiederholen Sie den Befehl, falls der vorherige Zustand benötigt wird.
