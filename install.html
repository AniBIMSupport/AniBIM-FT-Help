Installation & activationInstallation und Aktivierung

From request to ready in eight clear steps.Von der Anfrage bis zur Nutzung in acht klaren Schritten.

Use this process to install AniBIM FT for Autodesk Revit 2024–2027, start the built-in trial, and activate a commercial licence when required.Verwenden Sie diesen Ablauf, um AniBIM FT für Autodesk Revit 2024–2027 zu installieren, die integrierte Testversion zu starten und bei Bedarf eine kommerzielle Lizenz zu aktivieren.

1

Download or licenceTestversion oder Lizenz anfordern

Use the trial page or contact AniBIM Support.Nutzen Sie die Testversionsseite oder kontaktieren Sie den AniBIM-Support.

2

Receive installer linkInstaller-Link erhalten

Download the approved setup package.Laden Sie das freigegebene Installationspaket herunter.

3

Install AniBIM FTAniBIM FT installieren

Run the AniBIM FT installer and select the installed Revit versions you want to support (2024–2027).Führen Sie den AniBIM-FT-Installer aus und wählen Sie die installierten Revit-Versionen aus, die unterstützt werden sollen (2024–2027).

4

Start RevitRevit starten

If no valid commercial licence is found, AniBIM FT starts the built-in trial automatically. Open Settings → License to view trial status and Machine ID.Wenn keine gültige kommerzielle Lizenz gefunden wird, startet AniBIM FT automatisch die integrierte Testversion. Öffnen Sie Einstellungen → Lizenz, um Teststatus und Maschinen-ID anzuzeigen.

5

Open License settingsLizenzeinstellungen öffnen

Open Settings → License to view trial status, remaining days and the Machine ID.Öffnen Sie Einstellungen → Lizenz, um Teststatus, verbleibende Tage und die Maschinen-ID anzuzeigen.

6

Request commercial licenceKommerzielle Lizenz anfordern

Use Request License in Settings → License. Send the prepared request with Gmail, your default email app, or copy the request details manually.Verwenden Sie Lizenz anfordern unter Einstellungen → Lizenz. Senden Sie die vorbereitete Anfrage über Gmail, Ihre Standard-E-Mail-App oder kopieren Sie die Anfragedaten manuell.

7

Install licence fileLizenzdatei installieren

When AniBIM Support returns the signed AniBIM_FT.lic file, choose Browse License File in Settings → License and select it.Wenn AniBIM Support die signierte Datei AniBIM_FT.lic zurücksendet, wählen Sie unter Einstellungen → Lizenz die Option Lizenzdatei auswählen und öffnen Sie die Datei.

8

LicensedLizenziert

The License page changes from the trial indication to green License Activated. AniBIM FT is ready in the same Revit session.Die Lizenzseite wechselt von der Testversionsanzeige zur grünen Anzeige Lizenz aktiviert. AniBIM FT ist in derselben Revit-Sitzung einsatzbereit.
