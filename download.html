Installation workflowInstallationsablauf

From installer to activation.Vom Installer bis zur Aktivierung.

  1. Download and run the approved installer.Laden Sie den freigegebenen Installer herunter und führen Sie ihn aus.
  2. Start any installed supported version: Autodesk Revit 2024, 2025, 2026 or 2027.Starten Sie eine installierte unterstützte Version: Autodesk Revit 2024, 2025, 2026 oder 2027.
  3. Open Settings → License to view or copy the Machine ID when you need a commercial licence.Öffnen Sie Einstellungen → Lizenz, um die Maschinen-ID für eine kommerzielle Lizenz anzuzeigen oder zu kopieren.
  4. Use Request License to contact AniBIM Support when you are ready to activate a commercial licence.Verwenden Sie Lizenz anfordern, um den AniBIM-Support zu kontaktieren, wenn Sie eine kommerzielle Lizenz aktivieren möchten.
  5. Install the received licence file.Installieren Sie die erhaltene Lizenzdatei.
