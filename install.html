Installation & activationInstallation und Aktivierung

From request to ready in eight clear steps.Von der Anfrage bis zur Nutzung in acht klaren Schritten.

Use this process when AniBIM FT opens the activation window in Revit.Verwenden Sie diesen Ablauf, wenn AniBIM FT das Aktivierungsfenster in Revit öffnet.

1

Request trial or licenceTestversion oder Lizenz anfordern

Use the trial page or contact AniBIM Support.Nutzen Sie die Testversionsseite oder kontaktieren Sie den AniBIM-Support.

2

Receive installer linkInstaller-Link erhalten

Download the approved setup package.Laden Sie das freigegebene Installationspaket herunter.

3

Install AniBIM FTAniBIM FT installieren

Run the installer for your Revit version.Führen Sie den Installer für Ihre Revit-Version aus.

4

Start RevitRevit starten

The activation window opens when no valid licence is found.Das Aktivierungsfenster öffnet sich, wenn keine gültige Lizenz gefunden wird.

5

Copy Machine IDMaschinen-ID kopieren

Copy the ID shown in the activation window.Kopieren Sie die im Aktivierungsfenster angezeigte ID.

6

Receive licence fileLizenzdatei erhalten

AniBIM Support sends the signed machine-bound licence.Der AniBIM-Support sendet die signierte maschinengebundene Lizenz.

7

Select licence fileLizenzdatei auswählen

Choose the received AniBIM_FT.lic file.Wählen Sie die erhaltene Datei AniBIM_FT.lic aus.

8

Start workingArbeit beginnen

AniBIM FT is ready in the same Revit session.AniBIM FT ist in derselben Revit-Sitzung einsatzbereit.
